
# кеш о загрузках в s3 (в формате .sqlite), сохраняемый скриптом upload из репозитория s3_tools

локальный sqlite-кеш нужен чтобы не мучать каждый раз удаленный s3-бакет
запросами для проверки md5 уже загруженных файлов

-------

git нужен для синхронизации этих sqlite-кешей между разными локальными компьютерами

данный способ синхронизации бинарников через гит - это костыль конечно.
но для бинарников небольшого размера приемлимое решение.

в будущем при необходимости придумать другое решение.

если папка .git забьется лишней историей, то просто пересоздать репозиторий заново.
